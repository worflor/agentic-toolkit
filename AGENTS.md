# AGENTS.md — Onboarding & Guidelines

This repository contains the specifications for the **Agentic Project System**, a two-document framework for structuring and maintaining repositories built for human and agent collaboration.

## Repository Map

- `README.md` — Public overview and philosophy of the two-document system.
- `AGENTS.md` — Worker onboarding layer and operating guidelines.
- `Agentic Project Startup.md` — The canonical specification for project information architecture, landmark files, document roles, and agent onboarding structure.
- `Project Shaping.md` — The canonical specification for project maintenance, reconciling sediment, archaeological discovery, and preserving project taste.

## Working Guidelines

- **Preserve Voice & Tone:** Edits to either specification should maintain their crisp, aphoristic voice, measured tone, and practical focus.
- **Keep the Two Documents in Harmony:** Startup governs *where knowledge lives*; Shaping governs *how knowledge stays true to reality*. Changes to one document's conceptual framing should be mirrored in the other.
- **Format:** Standard GitHub-flavored Markdown.
